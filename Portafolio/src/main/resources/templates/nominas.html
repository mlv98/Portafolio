Gestor de Nóminas

Es una solución inteligente para la administración de pagos que automatiza la creación, consulta y generación de recibos PDF. A través de una interfaz ágil, el sistema centraliza la información salarial, procesa los cálculos y almacena automáticamente los comprobantes en la nube para su distribución segura.

Descripción del Proyecto

Este sistema de gestión de nóminas es una solución enfocada en la digitalización y automatización del ciclo de vida de los pagos corporativos. El proyecto resuelve la ineficiencia de los registros manuales mediante una arquitectura integrada que permite crear nuevas nóminas, consultar el histórico de pagos y automatizar la generación de documentos legales. La solución centraliza la información para eliminar errores de cálculo y asegurar que cada registro sea auditable y accesible en tiempo real.

La interfaz del usuario ha sido desarrollada como una Power App (Canvas), proporcionando una experiencia intuitiva para el administrador. La persistencia de los datos se gestiona en Microsoft Dataverse, aprovechando su estructura de tablas relacionales para garantizar la integridad de la información sensible. Una vez generada la nómina, el sistema utiliza Power Automate para orquestar la lógica de negocio: el flujo extrae los datos, genera un archivo dinámico y lo convierte en un recibo PDF profesional. Finalmente, estos documentos se almacenan y organizan automáticamente en OneDrive for Business, facilitando su consulta posterior y permitiendo compartirlos de forma segura con los empleados.

Tecnologías usadas:
  • Microsoft Power Apps (Canvas): Diseño de la interfaz de usuario personalizada para la captura de datos y visualización de registros.
  • Microsoft Dataverse: Infraestructura de base de datos relacional para el almacenamiento seguro y escalable de la información de nóminas.
  • Microsoft Power Automate: Automatización del flujo de trabajo, procesamiento de datos y orquestación entre servicios.
  • OneDrive for Business: Gestión de almacenamiento en la nube para el resguardo y organización de los archivos PDF generados.
