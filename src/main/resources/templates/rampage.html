System.Description

Desarrollo Full Stack de una plataforma integral para gamers bajo arquitectura MVC. La funcionalidad core recae en un motor de compatibilidad de hardware algorítmico propio, que parsea requisitos técnicos obtenidos a la API rest de RAWG y los compara vectorialmente con una base de datos local de benchmarks.

La validación garantiza al usuario conocer si su ordenador ejecutará o no el juego antes de comprarlo. Toda la plataforma cuenta con encriptación BCrypt, seguridad con Spring Security 6 y consumo web via RestTemplate/WebClient en el ecosistema Spring Boot. Todo desplegado sobre una base de Front-End reactiva con Tailwind y Thymeleaf.
